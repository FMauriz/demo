# Política de Privacidad – Cancionero Ukelele

**Última actualización:** Noviembre de 2026

Esta Política de Privacidad describe cómo se gestionan los datos en nuestra aplicación de Cancionero para Ukelele (en adelante, "la Aplicación"). Nos tomamos muy en serio la privacidad de nuestros usuarios y operamos bajo un principio estricto de **cero recopilación de datos**.

## 1. Recopilación y Uso de Información
La Aplicación está diseñada para funcionar de manera **100% local y offline**. 

* **Datos Personales:** No solicitamos, recopilamos, almacenamos ni compartimos ningún tipo de información personal (como nombres, correos electrónicos, números de teléfono o ubicaciones).
* **Biblioteca de Canciones:** Todo el contenido, canciones creadas, editadas o importadas por el usuario se almacena exclusivamente de forma local en el dispositivo utilizando el almacenamiento interno (`localStorage`). Ningún archivo se envía a servidores externos.

## 2. Permisos del Dispositivo
Para ofrecer sus funciones principales, la Aplicación solicita los siguientes permisos estrictamente necesarios:

* **Cámara (`CAMERA`):** Se utiliza única y exclusivamente para escanear el código QR de emparejamiento entre el Anfitrión y los usuarios invitados. La Aplicación no graba, toma fotografías ni almacena imágenes de ningún tipo. Si el usuario lo prefiere, puede introducir la cadena alfanumérica manualmente sin activar la cámara.
* **Conexión de Red / WiFi:** Se requiere para establecer canales de comunicación directos de igual a igual (P2P a través de WebRTC) entre dispositivos en una misma red local o punto de acceso compartido. Esto permite sincronizar las pantallas de los músicos en tiempo real. No se utiliza para conectarse a servidores de internet ni para rastrear al usuario.

## 3. Seguridad y Cifrado
Dado que la sincronización se realiza de forma local mediante el protocolo WebRTC, los datos compartidos en la sala (como los textos de las canciones) se transmiten de extremo a extremo entre los dispositivos de los usuarios de forma cifrada de manera nativa por el protocolo. Al no existir una base de datos centralizada en la nube, no hay riesgo de filtraciones de datos externos.

## 4. Cambios en esta Política
Es posible que actualicemos nuestra Política de Privacidad de vez en cuando si añadimos nuevas funciones locales. Se recomienda revisar esta página periódicamente para comprobar cualquier cambio.
